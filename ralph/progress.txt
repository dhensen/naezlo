## Codebase Patterns

(Reusable patterns go here. Keep this section short and current.)

- Stack and domain rules: see DECISIONS.md.
- A git remote named origin exists (since US-018): commit, then `git push origin main`.
- pnpm is not installed; use npm for the frontend.
- Frontend (frontend/, since US-027): `npm --prefix frontend install`, then `npm --prefix frontend run
  dev | build | lint | typecheck | test`. lint, typecheck and test are quality checks. Vite 8, React 19,
  `react-router` 8, Tailwind 4 (`@tailwindcss/vite`), vitest + Testing Library, TypeScript 6.0 (not 7:
  typescript-eslint). Product name: `APP_NAME` in frontend/src/config.ts. Pages: src/pages/<Name>Page.tsx,
  routes in src/App.tsx, tests `*.test.tsx` next to the code (render `<App />` in a `MemoryRouter`).
- Frontend API (since US-028): after any route or API model change run `npm --prefix frontend run
  gen:api` (writes frontend/openapi.json + src/api/schema.d.ts, both committed; tests/test_openapi.py
  fails otherwise). Calls: `unwrap(api.GET('/api/...'))` (src/api/client.ts) inside TanStack Query
  hooks; errors are `ApiError`, shown with `<ErrorMessage error={...} />`. Auth: src/auth/ (`useMe`,
  `RequireAuth`, `safeNextPath`); new pages go inside the guard + `AppLayout` in App.tsx. Tests:
  `mockApi({...})` (src/test/api.ts) then `renderApp('/path')` (src/test/render.tsx).
- E2E (since US-029): `npm --prefix frontend run e2e` is a quality check (needs `docker compose up -d`
  and once `npx --prefix frontend playwright install chromium`). It builds the frontend; Playwright
  starts `uv run python -m todolist.e2e --port 8765` (database todolist_e2e, emptied + migrated at
  every start, dev-login on). Specs: frontend/e2e/*.spec.ts; sign in with `const user = await
  signIn(page)` from `./helpers.ts` (unique email per call, `user.organizationName`, also
  `signOut(page, user)`, `uniqueUser()`). Tests share the database: assert only on your own data.
- Backend-owned paths are listed in frontend/src/backendPaths.ts (`BACKEND_PATHS`, dev proxy) and
  src/todolist/frontend.py (`BACKEND_PREFIXES`, never answered by the SPA fallback); keep them equal.
  FastAPI serves frontend/dist when it exists at startup (`FRONTEND_DIST`); tests have it off.
- App shell (since US-030): organization pages are routes under `/o/:orgSlug` inside `AppLayout`

  `GET /api/orgs/${ACME.id}/projects` when rendering `/o/acme`. E2E: the user's slug comes from
